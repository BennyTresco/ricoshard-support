# RicoShard — support and privacy

The two pages Apple requires a listing to link to, served by GitHub Pages.

- `index.html` — support and contact
- `privacy.html` — privacy policy

They are self-contained: no build step, no external files, no tracking. Edit
them here and push; Pages redeploys on its own.

The originals live in the game's own repository under `Store/site/`. If they are
changed there, copy them across rather than editing only one.
